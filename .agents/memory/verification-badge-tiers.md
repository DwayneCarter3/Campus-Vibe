name: Verification badge tiers
description: Public verification tiers and the rule against inferring a vendor-specific badge.
---

Public user headers do not display CEO, Admin, Moderator, or campus-title badges. Show the green outlined Student Verified pill for an approved student; add the Green Tick only for Student_Verified, or the Premium Blue Tick only for Premium_Approved. Apply the same account-tier rules to marketplace vendors, posts, comments, and profiles. Gold is a visual option, not an automatically assigned business-vendor entitlement.

**Why:** The user explicitly wants public identity headers free of personal roles and wants paid verification distinguished from basic student approval. Student verification and listing promotion do not establish a vendor-specific paid entitlement.

**How to apply:** Use the specific verification status, not a general isVerified boolean, to choose public marks. Keep role labels and moderation controls inside the private dashboard. Define and check a dedicated entitlement before assigning any vendor-specific gold badge.
